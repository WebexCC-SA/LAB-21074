# Lab Learning Objectives

Upon completion of this lab, you will be able to:

* Understand AI Receptionist Architecture and Value Proposition
* Navigate and Configure AI Receptionist in Collaboration Control Hub
* Develop and Implement AI Communication Guidelines
* Manage Knowledge Bases for Intelligent Responses
* Design Intent-Based Call Routing and Escalation Paths
* Respond to common customer inquiries using a configured knowledge base
* Escalate calls seamlessly to human agents using Customer Assist
* Experience how combining AI Receptionist with Customer Assist enriches the customer experience
* Simulate end-to-end, real-world customer interaction scenarios
* Enhance 24/7 support accessibility and customer satisfaction through integrated AI and real-time human interaction

These are the **high-level tasks** to achieve the objectives of this lab:

1. Access Collaboration Control Hub and provision an AI Receptionist instance
2. Validate PSTN and Number Assignment for the users
3. Configure the AI Receptionist persona and operational guidelines
4. Build and populate the AI Receptionist Knowledge Base
5. Define and map call routing
6. Validate the AI Receptionist workflow and call escalation
7. Configure Customer Assist with a queue and Agent configuration
8. Configure Customer Assist with TTS prompt, screen popup
9. Once Customer Assist configured with the features, attendees will be able to validate end-to-end call flow starting with AI Receptionist and finishing it with transfers to Realtime human agent
